Start with [`@easy-web/core`](./core/), the base package. The add-ons are [`@easy-web/cms-adapters`](./cms-adapters/) and [`@easy-web/auth`](./auth/), plus `@easy-web/swa` and `@easy-web/brand`. The `theme-core`, `i18n` and `content-blocks` pages document deprecated compatibility packages; see [Migrating to core](../guides/migrating-to-core/).
