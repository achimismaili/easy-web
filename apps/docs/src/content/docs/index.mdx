## Packages

easy-web is one base package plus optional add-ons:

| Package | Role | Description |
| ------- | ---- | ----------- |
| `@easy-web/core` | Base | Theme tokens, i18n, SEO, markdown, 31 Astro components and the content contracts |
| `@easy-web/cms-adapters` | Add-on | Decap CMS: typed content definitions and the admin page |
| `@easy-web/swa` | Add-on | Azure Static Web Apps 404 integration |
| `@easy-web/auth` | Add-on | MSAL.js authentication, Microsoft Graph integration |
| `@easy-web/brand` | Add-on | Favicon and icon generation |
| `@easy-web/create` | Reserved | Future scaffold CLI |

`@easy-web/theme-core`, `@easy-web/i18n`, `@easy-web/content-blocks`, `@easy-web/seo` and `@easy-web/markdown` are deprecated compatibility packages that re-export core. See [Migrating to core](./guides/migrating-to-core/).

## Why easy-web?

The ismaili.de web ecosystem runs multiple site instances for different organisations. Instead of copy-pasting components between sites, easy-web packages them once — so a bug fix or new feature lands in **every instance simultaneously** via a version bump.

## Quick Start

```bash
# Install the base package
pnpm add @easy-web/core

# Import the tokens in your Astro layout
# import '@easy-web/core/styles/tokens.css';
```

See [Installation →](./getting-started/installation/) for the complete setup guide.
