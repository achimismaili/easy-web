## Hero Component

The `Hero` component renders a full-width introductory section.

### Usage

```astro
---
import Hero from '@easy-web/core/components/Hero';
---
<Hero
  title="Build multilingual sites on one set of components"
  subtitle="Design tokens, bilingual routing and accessible Astro components from @easy-web/core."
  ctaLabel="Read the installation guide"
  ctaHref="/easy-web/docs/getting-started/installation/"
/>
```

The Hero owns a page-level `<h1>`, so this documentation page shows its source rather than embedding a second document heading. The [component gallery](/easy-web/components/#hero) renders the live component on its own page surface.

## ThemeToggle Component

The `ThemeToggle` component switches between light and dark themes using the CSS custom properties from `@easy-web/core/styles/tokens.css`.

### Usage

```astro
---
import ThemeToggle from '@easy-web/core/components/ThemeToggle';
---
<!-- Place in your site Header -->
<ThemeToggle lang="en" />
```

### How It Works

The toggle switches the `data-theme` attribute on `<html>` between `light` and `dark`. The token stylesheet uses this attribute to apply the correct CSS custom property values.

```css
/* tokens.css applies tokens like this: */
[data-theme="dark"] {
  --ew-surface: #111827;
  --ew-on-surface: #f9fafb;
  /* ... */
}
```

:::note[Not rendered on this page]
This site uses Starlight's own theme switcher, which owns the `data-theme` attribute on `<html>`, so a working `ThemeToggle` is left out here. Both switchers use the same attribute: when you change the theme of this site, every preview on the page follows it. See the toggle itself in the [component gallery](/easy-web/components/#theme-toggle).
:::

## CardGrid Component

The `CardGrid` component renders a responsive grid of cards. Each `Card` takes one `item`: a title, an optional description, an optional image with its alt text, and an optional `href` that turns the card into a link.

### Usage

```astro
---
import CardGrid from '@easy-web/core/components/CardGrid';
import Card from '@easy-web/core/components/Card';
---
<CardGrid>
  <Card item={{ title: 'Design tokens', description: 'One stylesheet of --ew-* custom properties themes every component, in light and dark.' }} />
  <Card item={{ title: 'Content contracts', description: 'Cards, galleries and structured data read one shared shape.' }} />
  <Card item={{ title: 'Static output', description: 'Components render to HTML at build time, so a built site is plain static files.' }} />
</CardGrid>
```

## Section Component

The `Section` component wraps content in a semantically correct `<section>` element with consistent spacing.

### Usage

```astro
---
import Section from '@easy-web/core/components/Section';
---
<Section title="Why easy-web" id="why">
  <p>One change to a shared component reaches every site that installs it.</p>
</Section>
```

## Using Components Together

Here is a typical page structure using multiple easy-web components:

```astro
---
import '@easy-web/core/styles/tokens.css';
import Hero from '@easy-web/core/components/Hero';
import Section from '@easy-web/core/components/Section';
import CardGrid from '@easy-web/core/components/CardGrid';
import Card from '@easy-web/core/components/Card';
import Header from '@easy-web/core/components/Header';
import Footer from '@easy-web/core/components/Footer';
import ThemeToggle from '@easy-web/core/components/ThemeToggle';
---
<html lang="en">
  <body>
    <Header siteName="My Site" navItems={[]} currentLang="en" pathname="/">
      <ThemeToggle slot="actions" />
    </Header>

    <Hero
      title="My Site"
      subtitle="Powered by easy-web"
      ctaLabel="Get Started"
      ctaHref="/docs"
    />

    <Section title="Features">
      <CardGrid>
        <Card item={{ title: 'Fast', description: 'Optimised for performance' }} />
        <Card item={{ title: 'Accessible', description: 'WCAG 2.1 compliant' }} />
        <Card item={{ title: 'Themeable', description: 'Light and dark mode built-in' }} />
      </CardGrid>
    </Section>

    <Footer siteName="My Site" legalLinks={[{ label: 'Privacy', href: '/privacy/' }]} />
  </body>
</html>
```
