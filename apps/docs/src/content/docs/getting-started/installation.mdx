## Prerequisites

- **Node.js 22** or later (pin with [Volta](https://volta.sh): `volta install node@22`)
- **pnpm 9** or later
- An **Astro 6 or 7** project

## Install the base package

`@easy-web/core` gives you a working site on its own: design tokens, theme helpers, i18n, SEO, the markdown plugin, all page components and the content contracts.

```bash
pnpm add @easy-web/core
```

Import the token stylesheet in your Astro layout:

```astro
---
import '@easy-web/core/styles/tokens.css';
---
```

## Add-ons

Add only what you need.

### CMS Adapters: Decap CMS and typed content definitions

```bash
pnpm add @easy-web/cms-adapters
```

### Static Web Apps: shared 404 handling on Azure

```bash
pnpm add @easy-web/swa
```

### Authentication: MSAL.js wrapper

```bash
pnpm add @easy-web/auth
```

:::note
Auth components require a single React island per page. See the [auth package docs](../../packages/auth/) for details.
:::

### Brand: favicon and icon generation

```bash
pnpm add -D @easy-web/brand
```

## Compatibility packages

`@easy-web/theme-core`, `@easy-web/i18n`, `@easy-web/content-blocks`, `@easy-web/seo` and `@easy-web/markdown` still install and work, but they only re-export `@easy-web/core` and are removed in 2.0. Don't add them to a new site. See [Migrating to core](../../guides/migrating-to-core/).
