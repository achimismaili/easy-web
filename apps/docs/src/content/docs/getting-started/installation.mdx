## Prerequisites

- **Node.js 22** or later (pin with [Volta](https://volta.sh): `volta install node@22`)
- **pnpm 9** or later
- An **Astro 5** project

## Install Individual Packages

Each package is independently installable. Add only what you need:

### Theme Core — CSS tokens + light/dark theme

```bash
pnpm add @easy-web/theme-core
```

Import the theme stylesheet in your Astro layout:

```astro
---
import '@easy-web/theme-core/theme.css';
---
```

### i18n Helpers

```bash
pnpm add @easy-web/i18n
```

### Content Blocks — Astro UI Components

```bash
pnpm add @easy-web/content-blocks
```

### Authentication — MSAL.js wrapper

```bash
pnpm add @easy-web/auth
```

:::note
Auth components require a single React island per page. See the [auth package docs](../packages/auth/) for details.
:::

### CMS Adapters — Decap CMS integration

```bash
pnpm add @easy-web/cms-adapters
```

## Install All Packages at Once

```bash
pnpm add @easy-web/theme-core \
         @easy-web/i18n \
         @easy-web/content-blocks \
         @easy-web/auth \
         @easy-web/cms-adapters
```
