## Using the Scaffold CLI

The `@easy-web/create` CLI scaffolds a new Astro site pre-configured with all easy-web packages:

```bash
pnpm create @easy-web my-site
cd my-site
pnpm install
pnpm dev
```

:::note[In development]
The scaffold CLI is in active development. Check the [GitHub repo](https://github.com/achimismaili/easy-web) for the latest status.
:::

## Manual Setup

Bootstrap a new site instance manually:

### 1. Create an Astro project

```bash
pnpm create astro@latest my-site
cd my-site
```

### 2. Install easy-web

```bash
pnpm add @easy-web/core
```

`@easy-web/core` is the base package. Add-ons such as `@easy-web/cms-adapters` or `@easy-web/swa` are optional.

### 3. Add the theme to your base layout

```astro
---
// src/layouts/Base.astro
import '@easy-web/core/styles/tokens.css';
import { noFlashScript } from '@easy-web/core/theme';
import PageShell from '@easy-web/core/components/PageShell';
import Header from '@easy-web/core/components/Header';
import Footer from '@easy-web/core/components/Footer';
import ThemeToggle from '@easy-web/core/components/ThemeToggle';

const lang = 'en';
const { pathname } = Astro.url;
---
<html lang={lang}>
  <head>
    <meta charset="utf-8" />
    <meta name="viewport" content="width=device-width" />
    <script is:inline set:html={noFlashScript} />
  </head>
  <body>
    <PageShell lang={lang}>
      <Header
        slot="header"
        lang={lang}
        siteName="My Site"
        navItems={[{ label: 'Home', href: '/' }]}
        currentLang={lang}
        pathname={pathname}
      >
        <ThemeToggle slot="actions" lang={lang} />
      </Header>
      <slot />
      <Footer
        slot="footer"
        lang={lang}
        siteName="My Site"
        legalLinks={[{ label: 'Privacy', href: '/privacy/' }]}
      />
    </PageShell>
  </body>
</html>
```

The `actions` slot replaces the header's default controls (theme toggle plus language switch). Leave it out to keep the defaults.

### 4. Configure i18n (optional)

```typescript
// astro.config.mjs
import { defineConfig } from 'astro/config';

export default defineConfig({
  i18n: {
    defaultLocale: 'en',
    locales: ['en', 'de'],
  },
});
```

### 5. Add i18n helpers

```typescript
// Use localizedHref for locale-aware links
import { localizedHref } from '@easy-web/core/i18n';

const link = localizedHref('/about', 'de'); // → '/de/about'
const defaultLink = localizedHref('/about', 'en'); // → '/about'
```

## Project Structure

```
my-site/
├── src/
│   ├── components/        # Site-specific components
│   ├── layouts/
│   │   └── Base.astro     # Uses @easy-web/core
│   ├── pages/
│   │   ├── index.astro
│   │   └── [lang]/        # i18n routes
│   └── content/           # Astro content collections
├── public/
├── astro.config.mjs
└── package.json
```
